# CodingAgent

## Balloon Reading Game (Python)

Simple reading game for 1st-grade kids:
- asks for kid name
- shows a clickable balloon
- opens a popup with one very easy sentence
- gives a sticker score when a sticker button is clicked
- uses a set of 100 easy sentences and cycles randomly without repeating until all are used

## Run

```bash
python reading_game.py
```

Requires Python with Tkinter support.
